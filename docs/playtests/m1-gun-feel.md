# M1 gun-feel playtest

Gate for M1 (plan 08 Task 5, PRD risk "combat feels flat"). **Status: not run yet.**

## Setup

1. `vp run dev`, open `http://localhost:5173/?scene=sandbox&spawn=rivet-smg,breach-shotgun,crawler,crawler,sentry-drone`, click **Start run**.
2. Keys: `E` pick up, `Q`/wheel swap, `Shift` dash, `RMB`/`Space` Overcharge, `3` spawn Crawler, `4` spawn Drone, `G` god mode, `1` 300-bullet ring, `2` clear bullets.

## Protocol (per tester, ~5 minutes)

Play freely with the pistol, SMG and shotgun against Crawlers and Drones, then ask:

1. Does shooting feel good? (1–5)
2. Which gun feels best, and which worst? Why?
3. Did anything feel delayed or mushy (input, hits, sound)?
4. Could you tell when you got hit? When an enemy was about to attack?
