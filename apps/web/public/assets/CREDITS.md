# Asset credits

- **Sprites, tilesets and story cards** (`sprites/*`, `tilemaps/tiles-s*.png`, `cards/*`): drawn by `scripts/gen-art.ts` (`vp run @dh/web#art`) from the game palette. Original, public domain.
- **Placeholder art** (pickups, props, effects): generated at runtime in `src/game/content/textures.ts`. Original, public domain.
- **Music** (`audio/music/*.wav`, 6 loops): synthesised by `scripts/gen-music.ts` (`vp run @dh/web#music`). Original, public domain.
- **Placeholder SFX** (`audio/sfx/*.wav`): synthesised by `scripts/gen-sfx.ts` (`node scripts/gen-sfx.ts`). Original, public domain.

- **UI font:** Silkscreen by Jason Kottke and The Silkscreen Project Authors, https://github.com/googlefonts/silkscreen, SIL Open Font License 1.1 (`fonts/OFL-Silkscreen.txt`), checked 2026-10-24.

Every added third-party pack gets an entry here: name, author, URL, licence, date checked.
